Касательная в точке x₀ = 1: y = 2x − 1 Значение производной: f′(x₀) = 2
Степенная функция задаётся формулой y = xᵖ, где p — любое рациональное число. Поведение её графика и свойства полностью зависят от значения показателя степени. Ниже приведены пять основных случаев, изучаемых в школьном курсе.

СЛУЧАЙ 1 Показатель — чётное натуральное число

y = x², y = x⁴, y = x⁶, …

Если степень принимает значения 2, 4, 6 и так далее, функция становится чётной. График симметричен относительно оси ординат (оси Oy). Самый известный пример — парабола.

  • ОДЗ: (−∞; +) — все действительные числа
  • Область значений: [0; +∞)
  • Чётность: функция чётная, f(−x) = f(x)
  • Монотонность: убывает на (−; 0], возрастает на [0; +∞)
  • График проходит через точки: (0; 0), (1; 1), (−1; 1)

СЛУЧАЙ 2 Показатель — нечётное натуральное число

y = x³, y = x⁵, y = x⁷, …

Когда показатель равен 3, 5, 7 и т. д., функция называется нечётной. Её график симметричен относительно начала координат. Классический представитель — кубическая парабола.

  • ОДЗ: (−∞; +∞) — все действительные числа
  • Область значений: (−∞; +∞)
  • Чётность: функция нечётная, f(−x) = −f(x)
  • Монотонность: возрастает на всей области определения
  • График проходит через точки: (0; 0), (1; 1), (−1; −1)

СЛУЧАЙ 3 Показатель — отрицательное целое число

y = x⁻¹ = 1/x,   y = x⁻² = 1/x², …

Отрицательная степень «опускает» переменную в знаменатель: x⁻ᵖ = 1/xᵖ. Базовое математическое правило запрещает делить на нуль, поэтому x ≠ 0. График распадается на две ветви, которые никогда не пересекают оси координат. При p = −1 графиком является гипербола.

  • ОДЗ: (−∞; 0) ∪ (0; +∞)
  • Область значений: (−∞; 0) ∪ (0; +∞)
  • Чётность: чётная, если |p| чётно; нечётная, если |p| нечётно
  • Монотонность: убывает на каждом из промежутков (при a > 0)
  • Асимптоты: x = 0 (вертикальная), y = 0 (горизонтальная)

СЛУЧАЙ 4 Показатель — положительная дробь

y = x^(1/2) = √x,   y = x^(1/3) = ∛x,   y = x^(m/k)

Дробная степень означает переход к корню: x^(m/k) = √(x). В школьном курсе степенная функция с нецелым показателем рассматривается только для неотрицательных значений x. График выглядит как плавная ветвь, выходящая из начала координат и уходящая вправо и вверх.

  • ОДЗ: [0; +∞)
  • Область значений: [0; +∞)
  • Чётность: функция общего вида (не является ни чётной, ни нечётной)
  • Монотонность: возрастает на всей области определения
  • График проходит через точки: (0; 0), (1; 1)

СЛУЧАЙ 5 Показатель равен нулю

y = x⁰ = 1,   x ≠ 0

У функции y = x⁰ есть особенность: любое число в нулевой степени даёт единицу. Графиком является горизонтальная прямая y = 1. Однако выражение 0⁰ не имеет смысла, поэтому точка с координатой x = 0 выкалывается — на графике остаётся пустая отметка на сплошной прямой.

  • ОДЗ: (−∞; 0) ∪ (0; +∞)
  • Область значений: {1} — единственное значение
  • Чётность: функция чётная
  • Монотонность: постоянна на всей области определения
  • Особая точка: «прокол» в точке (0; 1)

📘 Базовый уровень
БАЗОВЫЙ · №1
Найдите значение функции f(x) = x³ в точке x = −2.
Решение: f(x) = x³ Подставляем x = −2: f(−2) = (−2)³ = (−2)·(−2)·(−2) = −8 Ответ: −8
БАЗОВЫЙ · №2
Определите, является ли функция f(x) = x⁴ чётной, нечётной или общего вида.
Решение: Проверяем условие чётности: f(−x) = f(x) f(−x) = (−x)⁴ = (−1)⁴·x⁴ = 1·x⁴ = x⁴ = f(x) Условие чётности выполнено.

Правило: если показатель степени чётный — функция чётная.

Ответ: чётная
БАЗОВЫЙ · №3
Найдите область определения функции f(x) = x⁻².
Решение: Преобразуем функцию: f(x) = x⁻² = 1/x² Функция не определена, когда знаменатель равен нулю: x² = 0 ⇒ x = 0 Значит, область определения — все действительные числа, кроме нуля.

Ответ: (−∞; 0) ∪ (0; +∞)
БАЗОВЫЙ · №4
Найдите значение производной функции f(x) = x² в точке x = 3.
Решение: Находим производную по формуле (xⁿ)′ = n·xⁿ⁻¹: f′(x) = (x²)′ = 2x Вычисляем значение в точке x = 3: f′(3) = 2·3 = 6 Ответ: 6
БАЗОВЫЙ · №5
Решите уравнение x³ = 27.
Решение: Функция y = x³ нечётная и монотонно возрастает на всей области определения, поэтому уравнение x³ = a имеет ровно один корень при любом a. x³ = 27 ⇒ x = ∛27 = 3 Проверка: 3³ = 27 ✓

Ответ: x = 3
БАЗОВЫЙ · №6
На каком промежутке функция f(x) = x² убывает?
Решение: Функция f(x) = x² — парабола с ветвями вверх и вершиной в точке (0; 0). Левая ветвь параболы идёт вниз при движении слева направо, то есть функция убывает при x ≤ 0.

Через производную: f′(x) = 2x < 0 при x < 0.

Ответ: (−∞; 0]
📗 Профильный уровень
ПРОФИЛЬ · №1
Найдите значение производной функции f(x) = x³ в точке x = 2.
Решение: Находим производную по формуле (xⁿ)′ = n·x⁻¹: f′(x) = (x³)′ = 3x² Вычисляем значение в точке x = 2: f′(2) = 3·2² = 3·4 = 12 Ответ: 12
ПРОФИЛЬ · №2
В какой точке графика функции f(x) = x² касательная параллельна оси Ox?
Решение: Касательная параллельна оси Ox, когда её угловой коэффициент равен нулю, то есть f′(x₀) = 0. f′(x) = (x²)′ = 2x Приравниваем к нулю: 2x = 0 ⇒ x = 0 В точке x = 0 функция имеет минимум, касательная горизонтальна.

Ответ: x = 0
ПРОФИЛЬ · №3
Напишите уравнение касательной к графику функции f(x) = x³ в точке x₀ = 1.
Решение: Уравнение касательной: y = f′(x₀)(x − x₀) + f(x₀)

Шаг 1: f(x₀) = f(1) = 1³ = 1
Шаг 2: f′(x) = 3x², значит f′(1) = 3·1² = 3
Шаг 3: подставляем в формулу: y = 3·(x − 1) + 1 = 3x − 3 + 1 = 3x − 2 Ответ: y = 3x − 2
ПРОФИЛЬ · №4
Найдите абсциссу точки, в которой касательная к графику функции f(x) = x³ параллельна прямой y = 12x + 5.
Решение: Две прямые параллельны, если их угловые коэффициенты равны. У прямой y = 12x + 5 угловой коэффициент k = 12.

Значит, нужно найти x₀, при котором f′(x₀) = 12: f′(x) = 3x² 3x₀² = 12 ⇒ x₀² = 4 ⇒ x₀ = ±2

Ответ: x = ±2
ПРОФИЛЬ · №5
Найдите точку максимума функции f(x) = x³ − 3x².
Решение: Шаг 1: Находим производную: f′(x) = 3x² − 6x = 3x(x − 2) Шаг 2: Находим критические точки (f′(x) = 0): 3x(x − 2) = 0 ⇒ x = 0 или x = 2 Шаг 3: Определяем знак производной на промежутках:
• при x < 0: f′(x) > 0 (функция возрастает)
• при 0 < x < 2: f′(x) < 0 (функция убывает)
• при x > 2: f′(x) > 0 (функция возрастает)

В точке x = 0 производная меняет знак с «+» на «−» — это точка максимума.

Ответ: x = 0
ПРОФИЛЬ · №6
Найдите наименьшее значение функции f(x) = x³ − 3x на отрезке [0; 2].
Решение: Шаг 1: Находим производную: f′(x) = 3x² − 3 = 3(x² − 1) = 3(x−1)(x+1) Шаг 2: Критические точки: x = 1 и x = −1. На отрезке [0; 2] лежит только x = 1.

Шаг 3: Вычисляем значения функции в критической точке и на концах отрезка: f(0) = 0³ − 3·0 = 0 f(1) = 1³ − 3·1 = 1 − 3 = −2 f(2) = 2³ − 3·2 = 8 − 6 = 2

Наименьшее из этих значений: −2.

Ответ: −2
ПРОФИЛЬ · №7
Найдите угловой коэффициент касательной к графику функции f(x) = √x в точке x₀ = 4.
Решение: Запишем функцию в виде степенной: f(x) = √x = x^(1/2) Находим производную по формуле (xⁿ)′ = n·xⁿ⁻¹: f′(x) = (1/2)·x^(1/2 − 1) = (1/2)·x^(−1/2) = 1/(2√x) Вычисляем в точке x₀ = 4: f′(4) = 1/(2·√4) = 1/(2·2) = 1/4

Ответ: 1/4
ПРОФИЛЬ · №8
На промежутке (−∞; 0) функция f(x) = x⁻² является:
Решение: Запишем функцию: f(x) = x⁻² = 1/x².

Находим производную: f′(x) = −2x⁻³ = −2/x³ При x < 0 знаменатель x³ < 0, значит: f′(x) = −2/(отрицательное) > 0 Производная положительна на всём промежутке (−∞; 0), следовательно функция возрастает.

Геометрически: левая ветвь гиперболы y = 1/x² идёт снизу вверх при движении слева направо.

Ответ: возрастающей
